# GCP CI/CD Examples

Esta carpeta incluye flujos de trabajo para desplegar código en servicios de Google Cloud.

## Casos

- **C1 – Python → Cloud Functions con GitHub Actions**
  - Carpeta: `CloudFunctions/PythonFunction`
  - Workflow: `gcp-cloudfunctions-python.yml`

- **C2 – Node.js → Cloud Functions con GitHub Actions**
  - Carpeta: `CloudFunctions/NodeFunction`
  - Workflow: `gcp-cloudfunctions-node.yml`

- **C3 – Python → Cloud Run (Docker) con GitHub Actions**
  - Carpeta: `CloudRun/PythonAPI`
  - Workflow: `gcp-cloudrun-python.yml`

- **C4 – Node.js → Cloud Run (Docker) con GitHub Actions**
  - Carpeta: `CloudRun/NodeAPI`
  - Workflow: `gcp-cloudrun-node.yml`
