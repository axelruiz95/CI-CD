# Azure CI/CD Examples

Esta carpeta contiene ejemplos de despliegue continuo para distintos servicios de Azure.

## Casos

- **A1 – Python → Azure Functions con GitHub Actions**
  - Carpeta: `Functions/PythonFunction`
  - Workflow: `azure-functions-python.yml`

- **A2 – Node.js → Azure App Service con GitHub Actions**
  - Carpeta: `AppService/NodeApp`
  - Workflow: `azure-appservice-node.yml`

- **A3 – Python → Azure App Service con Azure Pipelines**
  - Carpeta: `AppService/PythonApp`
  - Pipeline: `azure-pipelines.yml`
